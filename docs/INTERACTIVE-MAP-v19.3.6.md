# Interactive Director map — v19.3.6

Director Mode continues to use the bundled dependency-free OpenStreetMap viewer. No Google Maps API key is required.

The map supports:

- PWA GPS markers and recent trails
- Configured or inferred checkpoint markers
- Drag/pan, pinch zoom, mouse-wheel zoom, and +/− controls
- Fit-all markers
- Device/checkpoint details

The viewer requests standard OpenStreetMap tiles only for the visible viewport and displays attribution. It does not bulk-download or prefetch map tiles.
