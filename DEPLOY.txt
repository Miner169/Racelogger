RACE BIB LOGGER v19.3.3 — DEPLOYMENT
===================================

1. Upload the package contents to the same web root. Preserve the app/ and icons/ folders.
2. Replace Code.gs in the bound Google Apps Script project, save, and deploy a new Web App version.
3. Keep the Web App execution/access settings appropriate for the event deployment.
4. In Apps Script Project Settings > Script Properties, configure once for the deployment:
     GOOGLE_MAPS_BROWSER_API_KEY = your browser-restricted Maps JavaScript API key
     GOOGLE_MAPS_MAP_ID = optional Google Cloud Map ID
   Checkpoint users do not enter or store a Maps key on their device.
5. Restrict the browser key in Google Cloud to the deployed website origin and the Maps JavaScript API.
6. Confirm manifest.json, sw.js, app/ux-v1933.js, and app/ux-v1933.css are served from the same root.
7. On installed PWAs, close all app windows, reopen online once, and allow the service worker to update.
8. Validate on a real event device:
   - Quick Entry shows the large 123 keypad only.
   - ABC opens the phone keyboard and 123 returns to the large keypad.
   - Space input is rejected with red feedback.
   - Duplicate warning appears inside Quick Entry without scrolling.
   - Last 4 repeated BIB colours match the main Last 4 strip.
   - Race Command View scroll position remains stable.
   - Google map pans and zooms and displays PWA/checkpoint markers.

No Racelog sheet migration is required for v19.3.3.
