RACE BIB LOGGER v19.3.5 — DEPLOYMENT
===================================

1. Upload the complete package to the same web root. Preserve app/, icons/, scripts/, tests/ and docs/.
2. Replace Code.gs in the bound Google Apps Script project, save, and deploy a new Web App version.
3. No Google Maps key, Map ID or map credential is required. Director Mode uses OpenStreetMap.
4. Make sure sw.js, manifest.json, tailwind.css and every app/ file are deployed; v19.3.5 deliberately changes filenames and URL versions.
5. Open the website online once after deployment and refresh it.
6. For an installed PWA, fully close and reopen it once. The new service worker removes the old caches that contained the Google-key placeholder and earlier Quick Entry code.

RACE-DAY DEVICE CHECK
---------------------
- Open Quick BIB Entry and press ABC once. The native keyboard should open immediately.
- Type a BIB and press the small LOG beside backspace. It must start logging without manually lowering the keyboard.
- Test a duplicate BIB and confirm the duplicate decision is reachable.
- Open Runner Safety Log and confirm the first BIB starts directly under the header without an empty band.
- Open Director Mode and confirm the full RACE COMMAND VIEW title is visible.
- Confirm the map shows PWA markers and either configured or inferred checkpoint markers.
- Drag, pinch, use +/−, tap markers, and press ◎ to fit all locations.
- Confirm © OpenStreetMap contributors remains visible.

No Racelog sheet migration is required for v19.3.5.
